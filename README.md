# Campus Equipment Loans

DSC5003 Track 1 project for browsing campus equipment, checking items out and in, and reviewing overdue loans.

## Quick start

Requires Python 3.11 or later. From the repository root, run:

```powershell
cd code
python app.py --port 8001
```

Open http://127.0.0.1:8001/ in your browser. On the first run, the application creates a local SQLite database and loads sample data.
